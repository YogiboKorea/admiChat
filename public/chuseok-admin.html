만든 사진

해당하는 사진이 없습니다.

갤러리 공개 중은 고객이 "공개할게요"를 골라 갤러리에 보이는 사진입니다. 숨김을 누르면 갤러리에서만 빠지고(고객의 '내가 만든 사진'에는 남음), 그 회원의 공개 보너스 +1장도 빠집니다. 되돌리기로 다시 공개할 수 있습니다.
삭제는 기록과 이미지 파일을 모두 지웁니다 — 되돌릴 수 없습니다. 갤러리에서만 빼려면 숨김을 쓰세요. 완성·진행 중 건을 지우면 회원의 만들기 횟수가 하나 돌아가고, 적립 기록은 그대로 둡니다.

적립 확인 (예외 건만)

확인할 건이 없습니다 — 적립은 전부 자동으로 잘 들어갔습니다.

적립금은 고객이 결과 화면에서 버튼을 누르면 자동으로 지급됩니다(아이디당 1회). 평소엔 여기가 비어 있는 게 정상입니다.
여기에 뜨는 건 Cafe24 적립 API 를 불렀는데 응답이 오지 않아 들어갔는지 모르는 건(결과 불명)입니다. Cafe24 어드민 > 회원 > 적립금 내역에서 확인한 뒤 — 들어갔으면 지급 확인(기록만 확정), 안 들어갔으면 미지급 확인(기록 삭제 → 회원이 다시 받을 수 있음).
