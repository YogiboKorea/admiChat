적립 확인 (예외 건만)

확인할 건이 없습니다 — 적립은 전부 자동으로 잘 들어갔습니다.

적립금은 고객이 결과 화면에서 버튼을 누르면 자동으로 지급됩니다(아이디당 1회). 평소엔 여기가 비어 있는 게 정상입니다.
여기에 뜨는 건 딱 한 경우 — Cafe24 적립 API 를 불렀는데 응답이 오지 않아 들어갔는지 모르는 건(결과 불명)입니다. Cafe24 어드민 > 회원 > 적립금 내역에서 실제로 들어갔는지 본 뒤 — 들어갔으면 지급 확인(기록만 확정), 안 들어갔으면 미지급 확인(기록 삭제 → 회원이 버튼을 다시 눌러 받을 수 있음). "전체 적립 기록 보기"를 켜면 정상 지급된 건도 보입니다.
